# Security Policy

## Supported Versions

We actively support the latest release of the portfolio system and its associated open-source components with critical security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository or any hosted client assets:

1. **Do not disclose publicly**: Please refrain from creating public GitHub issues for security vulnerabilities.
2. **Contact Directly**: Email the maintainer at [rikeshvijay948@gmail.com](mailto:rikeshvijay948@gmail.com) with the subject line `[SECURITY] Vulnerability Report - Portfolio`.
3. **Include Details**:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept payload.
   - Potential impact assessment.
4. **Response Timeline**: You will receive an initial response acknowledging the report within 48 hours, followed by a remediation timeline.

Thank you for helping keep this project safe and secure!
